About

This monitor reads the agent's AWS S3 registry in real-time. The agent plays matches continuously and periodically proposes a settings change. Currently press_radius is the only auto-tuned parameter — the learning pipeline adjusts this value, evaluates its effect on match outcomes, and promotes or rejects it. All other parameters (pass_margin, shot_range, support_width) are fixed. Data is read-only from S3; nothing is written.
